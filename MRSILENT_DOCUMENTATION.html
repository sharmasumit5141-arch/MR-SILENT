📚 Syntax Guide

1. Variables

❌ Python (2 lines)

x = 10
name = "Sumit"

✅ MRSILENT (1 line)

x = 10, name = "Sumit"

2. Functions

Arrow Functions (Recommended)

add = (a, b) => a + b
greet = name => "Hello {name}"

3. Conditions

❌ If-Else (4 lines)

if x > 5:
    print("Big")
else:
    print("Small")

✅ Ternary (1 line)

x > 5 ? print("Big") : print("Small")

4. Loops

For Loop

loop(i, 0, 10) {
    print(i)
}

Array Iteration

[1, 2, 3, 4, 5].each { print($_) }

5. Arrays

arr = [1, 2, 3, 4, 5]

arr.map(x => x * 2)          // [2, 4, 6, 8, 10]
arr.filter(x => x > 2)       // [3, 4, 5]
arr.reduce((a,b) => a + b)   // 15
arr.sum()                     // 15

6. Objects

user = { name: "Sumit", age: 25, city: "Delhi" }

user.name        // "Sumit"
user["age"]      // 25
user.city        // "Delhi"

7. Strings

name = "MRSILENT"

"hello".upper()           // HELLO
"HELLO".lower()           // hello
"Hello {name}"            // Hello MRSILENT
"a,b,c".split(",")        // ["a","b","c"]
"hello world".length      // 11

Example 3: Telegram Bot

MRSILENT (8 lines)

import "telegram" as tg
import "database" as db

tg.cmd("start", u => tg.reply(u, "Welcome!"))
tg.cmd("balance", u => tg.reply(u, "Balance: ₹{db.get(u,'bal')}"))
tg.cmd("withdraw", (u, amt) => {
    int(amt) <= db.get(u,'bal') ? (db.save(u,'bal',db.get(u,'bal')-amt), tg.reply(u,"Success!")) : tg.reply(u,"Low!")
})
tg.run("YOUR_TOKEN")

🔌 API Reference

Console Functions

Function Description Example

🏆 Best Practices

1. Use Arrow Functions

❌ Bad

fn multiply(a, b) {
    return a * b
}

✅ Good

multiply = (a, b) => a * b

2. Chain Methods

❌ Bad

arr = [1,2,3,4,5]
filtered = arr.filter(x=>x>2)
mapped = filtered.map(x=>x*2)
result = mapped.sum()

✅ Good

result = [1,2,3,4,5].filter(x=>x>2).map(x=>x*2).sum()

3. Use Ternary for Simple Conditions

❌ Bad

if x > 5 {
    print("Big")
} else {
    print("Small")
}

✅ Good

x > 5 ? print("Big") : print("Small")

4. Use String Interpolation

❌ Bad

msg = "Hello " + name + ", age " + age

✅ Good

msg = "Hello {name}, age {age}"

Additional Tips

  • Keep functions small and focused
  • Use meaningful variable names
  • Leverage built-in methods
  • Test your code frequently
  • Write clear comments
